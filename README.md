# GameZone - Taller Móvil Flutter

Aplicación móvil desarrollada en Flutter y Dart como taller práctico de desarrollo móvil.

## Descripción

GameZone es una app con temática de videojuegos. Tiene tres secciones accesibles desde una barra de navegación inferior:

- **Home:** banner promocional de un torneo, carrusel horizontal de juegos destacados y publicaciones con botón de "Me gusta".
- **Chats:** lista de cinco conversaciones construidas con el widget reutilizable `ChatTile`.
- **Laboratorio de widgets:** contador de nivel del jugador con botones para aumentar, disminuir y reiniciar, con límites de 0 a 10.

## Conceptos aplicados

Widgets personalizados, Scaffold, AppBar, BottomNavigationBar, Row, Column, Container, Padding, SizedBox, ListView (vertical y horizontal), parámetros, variables, eventos con botones y setState().

## Cómo ejecutarlo

1. Instalar Flutter y tener un emulador o dispositivo conectado.
2. Clonar el repositorio:
   git clone URL_DE_TU_REPOSITORIO
3. Entrar a la carpeta del proyecto:
   cd NOMBRE_DE_LA_CARPETA
4. Instalar dependencias:
   flutter pub get
5. Ejecutar la app:
   flutter run

Nota: las imágenes se cargan desde internet, por lo que se necesita conexión.
